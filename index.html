プライバシーポリシー

最終更新日: 2026年8月6日 ／ 対象バージョン: 3.3.0

本プライバシーポリシーは、Chrome拡張機能「AI文字起こし」（以下「本拡張機能」）における ユーザーデータの取り扱いについて説明します。

本拡張機能は、画面や画像ファイルに写っている文字を読み取ってテキストに変換するツールです。 ユーザーが自分で選んだ画像だけを処理します。 どの画像を処理するか、およびその画像に何が写っているかは、すべてユーザーの選択によります。

1. 単一の目的（Single Purpose）

本拡張機能の唯一の目的:
ユーザーが指定した画像（画面の選択範囲・画面全体のキャプチャ・ローカルの画像ファイル・画像のURL）に 写っている文字を読み取り、テキストとして書き出してクリップボードにコピーすることです。
本拡張機能は、この目的以外の機能（広告表示・ユーザー追跡・SNS連携・第三者へのデータ販売・ 閲覧履歴の収集など）を一切持ちません。

2. 拡張機能が扱うデータ（収集する情報の種類）

本拡張機能は、ユーザーが文字起こしを実行した時にのみ、以下のデータを処理します。 Chrome ウェブストアのデータ使用フォームで申告する分類に合わせて開示します。

Chrome ウェブストアの分類 本拡張機能における具体的内容
ウェブサイトのコンテンツ ユーザーが文字起こしの対象として指定した画像そのもの。取得の方法は次の4つで、 いずれもユーザーがボタンを押した時にだけ取得されます。
①現在開いているタブの表示部分のキャプチャ（chrome.tabs.captureVisibleTab）
②上記キャプチャからユーザーがマウスで選択した範囲の切り抜き
③ユーザーが選択またはドラッグ＆ドロップしたローカルの画像ファイル
④ユーザーが入力欄に貼り付けた画像のURL（そのURLへ画像を取りに行きます）
ページのHTML・入力内容・Cookie を読み取ることはありません。 画像そのものは保存されず、処理が終わると破棄されます。
個人を特定できる情報／健康に関する情報 本拡張機能は、氏名や病名などをそれと分かる項目として取り出す処理を持っていません。 ただし、ユーザーが選んだ画像に氏名・日付・検査結果などが写っていれば、 それは画像の一部として読み取られ、文字起こし結果に含まれます。 AIモードを使う場合は、その画像が Google の Gemini API へ送信されます（第5章）。 どの画像を処理するかはユーザーが選択するため、個人情報を含む画像を扱うかどうかは ユーザーの判断と責任によります。
認証に関する情報 ユーザーが任意で登録する Google Gemini API キー（Google 社が発行し、ユーザー自身が取得したもの）。 ユーザーの端末内（chrome.storage.local）にのみ保存されます。 開発者のキーは使用せず、開発者へ送信されることもありません。

本拡張機能は、以下のデータを 収集しません: 氏名・生年月日・住所・電話番号などを項目として抽出する処理、位置情報、閲覧履歴、検索履歴、 金融情報・決済情報、生体情報（指紋・顔画像など）、ウェブサイトのログイン情報。

3. データの保管場所と保持期間

保存先はすべてユーザーのブラウザ内（chrome.storage.local）です。 開発者が運営するサーバーは存在しません。

  • 画像データ：保存しません。文字起こしの処理中だけメモリ上に存在し、 処理が終わると破棄されます。
  • 文字起こし結果：最大3件までブラウザ内に保存されます （4件目以降は古いものから順に上書きされます）。ポップアップの「消去」ボタンでいつでも削除できます。
  • Gemini API キー・使用するモデルの選択・自動実行の設定： ユーザーが変更または削除するまで保持されます。
  • 処理中の一時情報（どの保存枠を使うか等）：処理が終わるかキャンセルした時点で削除されます。
  • 保持期間：上記いずれも、ユーザーが削除するか拡張機能をアンインストールするまで 端末内に保持されます。開発者側にはいかなるデータも保持されないため、 開発者側での保持期間の定めはありません。

4. 拡張機能が要求する権限と用途

本拡張機能が manifest.json で要求する権限と、その用途は以下のとおりです。 いずれも本拡張機能の単一の目的を達成するために必要最小限のものです。

権限 用途
activeTab ユーザーがボタンを押した時に限り、現在開いているタブの表示部分を画像として取得するため。
scripting 範囲選択モードのとき、マウスで範囲を囲むための透明な操作画面をページ上に重ねるため。 ページの内容を読み取る処理は含みません。
storage 文字起こし結果（最大3件）・Gemini API キー・設定値をブラウザ内に保存するため。
offscreen 無料OCRモードの文字認識処理と、クリップボードへの書き込みを、 画面のない裏方のページで実行するため（ポップアップを閉じても処理を続けられるようにするため）。
clipboardWrite 文字起こし結果をクリップボードへコピーするため。
ホスト権限 https://generativelanguage.googleapis.com/* AIモードを使うとき、Google の Gemini API へ画像を送信して文字起こしを依頼するため。
ホスト権限 https://cdn.jsdelivr.net/*
https://raw.githubusercontent.com/*		 無料OCRモードで使う日本語・英語の文字認識用データファイルを取得（ダウンロード）するため。 これらの宛先へ画像やテキストを送信することはありません。

本拡張機能には、ショートカットキー（既定: Windows は Ctrl+Shift+4、Mac は Command+Shift+4）で 範囲選択モードを開始する機能があります。押した時にだけ動作し、常時監視は行いません。

5. 外部サービスへのデータ送信（第三者提供）

本拡張機能は、開発者が運営するサーバーへのデータ送信を一切行いません。 外部への通信は、次の3つだけです。

5-1. Google Gemini API（generativelanguage.googleapis.com）— AIモード使用時のみ

  • 実行タイミング：ユーザーが Gemini API キーを登録し、AIモードで文字起こしを実行した時のみです。 自動的な送信は行いません。
  • 送信内容：対象の画像そのもの（キャプチャした画像・選択範囲・ 指定したファイルや画像URLの中身）と、文字起こしを指示する固定の文章です。 画像に写っているものはそのまま送信されますので、 個人情報が写り込む画像を扱う場合は十分にご注意ください。
  • API キーの扱い：ユーザー自身が取得したキーを使用します。 キーは常に HTTP ヘッダー（x-goog-api-key）で送信し、URL には含めません。 通信は HTTPS で暗号化されます。送信先のサーバーは日本国外に所在する場合があります。
  • 無料キー利用時の注意：無料枠のキーで利用する場合、送信内容が Google 社の モデル改善学習に利用される可能性があります。学習に利用されたくない場合は、有料キーの利用および Google 社が提供する学習のオプトアウト設定を推奨します。
  • 送信されたデータの取り扱いは、Google 社の 「Gemini API 追加利用規約」 および「Google プライバシーポリシー」 に従います。

5-2. 文字認識用データの取得（cdn.jsdelivr.net ／ raw.githubusercontent.com）— 無料OCRモード使用時のみ

  • 無料OCRモードでは、文字認識をユーザーの端末内で行います。そのために必要な 言語データファイルを上記の配信元からダウンロードします。
  • 画像・文字起こし結果を送信することはありません。通信は取得（ダウンロード）方向のみです。

5-3. ユーザーが入力した画像URL

  • 画像URLを指定した場合、その URL へ画像を取りに行きます（宛先はユーザーが入力したサイトです）。 画像以外のデータを送ることはありません。

本拡張機能は、上記以外の第三者（広告事業者・分析事業者等）へのデータ提供・販売・貸与を一切行いません。 アクセス解析・エラー収集サービスは使用しておらず、無料OCRモードの実行に必要なプログラム本体は すべて拡張機能内に同梱しています。

6. 医療機関でご利用になる場合の注意（重要）

本拡張機能は一般的な文字起こしツールですが、検査報告書などの読み取りに使われることを想定した 指示文（プロンプト）を含んでいます。医療機関でご利用になる場合は、次の点にご留意ください。

  • AIモードでは、画像がそのまま Google の Gemini API へ送信されます。 患者氏名・検査日・検査結果などが写っている画像を AIモードで処理すると、 それらも一緒に送信されます。本拡張機能側で氏名等を伏せる（マスクする）処理は行っていません。
  • 患者情報を外部へ出したくない場合は、無料OCRモードをご利用ください。 無料OCRモードでは画像は端末の外へ出ません。
  • AIが事実でない内容を作らないための対策：AIへの指示文には 「画像に実際に書かれている内容のみを出力する」「推測・補完は禁止」「読み取れない場合は ［判読不能］と記載する」という制約を明記しています。ただし、AIの出力が常に正しいことを 保証するものではありません。
  • 患者情報を含む画像を扱うかどうかの判断、および所属機関の規程・ 個人情報保護法令の遵守は、利用者の責任において行ってください。

7. データの使用に関する誓約（Chrome ウェブストア開示事項）

  1. 本拡張機能で扱うユーザーデータは、ユーザーが承認した目的（指定された画像の文字起こし）の ためにのみ使用します。
  2. 本拡張機能で扱うユーザーデータを、第三者へ販売・貸与・譲渡しません。 承認された使用法に当てはまらない目的（マーケティング・広告等）でも、第三者へ転送することはありません。
  3. 本拡張機能で扱うユーザーデータを、信用力の判断や融資目的に使用したり、 そのような目的のために第三者へ転送することは一切ありません。

8. Google API ユーザーデータポリシー（Limited Use）への準拠

本拡張機能は、Google Gemini API を利用するにあたり、Google API サービスのユーザーデータポリシー （Limited Use 要件）を遵守します。

  • 取得したデータは、本拡張機能の単一の目的（画像の文字起こし）のためにのみ使用します。
  • 取得したデータを広告目的には一切使用しません。
  • 取得したデータを、開発者を含むいかなる人間が読み取ることもありません （Gemini API への送信時を除き、すべてユーザーの端末内で処理されます）。
  • 取得したデータを、本拡張機能のユーザーに結果を返す目的以外で第三者へ転送しません。

9. セキュリティ対策

  • 入力フォーム保護：Gemini API キーの入力欄は type="password" による マスク表示とし、autocomplete="off" でブラウザの補完履歴に残しません。
  • キーの送信方法：API キーは常に HTTP ヘッダーで送信し、URL には含めません。
  • 通信のセキュリティ：すべての通信は HTTPS で暗号化されます。
  • 同期しない：保存には chrome.storage.local のみを使用し、 Google アカウント経由で他の端末へ同期される chrome.storage.sync は使用しません。
  • リモートコードを実行しません：文字認識のプログラム本体は拡張機能に同梱しており、 外部から取得したスクリプトを実行することはありません （無料OCRモードで外部から取得するのは言語データのみです）。

10. ユーザーの権利（削除請求・開示請求）

本拡張機能が保存するデータ（文字起こし結果・Gemini API キー・設定値）は、 すべてユーザーの端末内にのみ存在します。ポップアップの「消去」ボタン、または Chrome の 拡張機能管理画面から、いつでも確認・削除できます。アンインストールすればすべて削除されます。 開発者側のサーバーにはデータを保持していないため、開発者に対して開示請求できる保存データはありません。

AIモードで Google 社へ送信された内容についての開示・削除請求は、Google 社の窓口へ 直接お問い合わせください。

11. 利用にあたっての補足（正確性・医療安全）

本拡張機能は文字の読み取りを補助するツールであり、診断・治療に関する判断や助言を行うものでは ありません。AI・OCR のいずれも読み取り誤りが起こり得ます。 書き出されたテキストは、必ずご自身で元の画像と見比べて確認してください。 確認しないまま診療録その他の重要な文書へ転記しないでください。

12. ポリシーの変更

本プライバシーポリシーは、必要に応じて改定される場合があります。改定があった場合は、本ページの最終更新日を更新します。
